## Program Induction Handoff Spec

### Goal
Build a Fleet-based program induction system that maps a binary target image to a posterior over turtle-style programs that approximately render that image.

### Project Layout
- `program-induction/Main.cpp`: Core C++ system (grammar, renderer, likelihoods, inference, formatting, trace logging).
- `program-induction/Makefile`: Build recipe for `main`.
- `program-induction/make_gallery.py`: Parallel gallery runner and HTML report generator.
- `program-induction/README.md`: Short usage docs.
- `program-induction/spec.md`: This handoff spec.

### Machine Requirements
- OS: macOS/Linux with `g++`/`clang++`.
- Python: 3.9+.
- Fleet source tree available at `../Fleet` relative to `program-induction/`.
  - The `Makefile` includes `../Fleet/Fleet.mk`.

### Setup On A New Machine
1. Clone this repository.
2. Ensure Fleet exists at `../Fleet` from `program-induction/` (or edit `FLEET_ROOT` in `program-induction/Makefile`).
3. Build:
   - `cd program-induction`
   - `make`
4. Quick smoke test:
   - `./main --mode enumerate --target-image gallery/targets/triangle.txt --width 80 --height 80 --enum-steps 200 --enum-method basic`

### Core Model

#### Program primitives
- Movement: `left`, `right`, `up`, `down`
- Pen state: `penup`, `pendown`
- Positioning: `jump(location)`, `jumpxy(x_idx,y_idx)`
- Composition: `seq(a,b)`, `concat(a,b)` (alias of `seq`)
- Repetition: `repeat2(p)` through `repeat100(p)`

#### Terminals
- Jump locations: `center`, `top_left`, `top`, `top_right`, `left_edge`, `right_edge`, `bottom_left`, `bottom`, `bottom_right`
- `jumpxy` indices: `0..9,a..f` (16 levels)

#### Rendering
- Binary raster canvas.
- Default canvas in gallery: `80x80`.
- Turtle step size parameterized by `--step-size` (default used in gallery: `6`).

#### Likelihood / image metrics
- `--noise-model bernoulli`
- `--noise-model dt`
- `--noise-model f1`
- `--noise-model bernoulli+dt`
- `--noise-model f1+dt`
- Key knobs:
  - `--epsilon` (bernoulli flip probability)
  - `--dt-weight`
  - `--f1-weight`

### Inference Modes
- `--mode infer`: MCMC via parallel tempering (`--chains`, `--max-temp`, `--steps`/`--time`).
- `--mode enumerate`: grammar enumeration (`--enum-method basic|partial|full`, `--enum-steps`).
- `--mode prior-test`: prior predictive recovery tests (`--prior-tests`, `--prior-steps`).

### Program Formatting
- `--program-format nested` (default): preserves repeat structure.
- `--program-format expanded`: explicitly unrolls repeats in printed output.

### Trace Logging (new)
- Full inference trace can be written in `infer` mode:
  - `--trace-path /abs/path/to/trace.tsv`
  - `--trace-every N`
- Trace format (TSV):
  - `sample`, `posterior`, `prior`, `likelihood`, `program`

### Progress Reporting
- `main` prints sampler progress with elapsed time and ETA:
  - `# progress infer ...`
  - `# progress enumerate ...`
- `make_gallery.py` prints:
  - per-target sampler progress relay (`[triangle] progress ...`)
  - global gallery progress (`[gallery] done/total ... eta=...`)

### Gallery Generation
- Script: `program-induction/make_gallery.py`
- Deterministic targets are generated by executing primitive programs (not direct pixel drawing).
- Typical usage:
  - Enumerate:
    - `python3 make_gallery.py --mode enumerate --enum-method full --enum-steps 30000 --workers 4 --noise-model f1+dt`
  - Infer (safer memory profile):
    - `python3 make_gallery.py --mode infer --steps 20000 --chains 4 --time 120s --workers 1 --noise-model f1+dt`
- Main output:
  - `program-induction/gallery/index.html`

### Reproducibility Notes
- Outputs depend on Fleet internals and random seeds (not currently pinned in CLI).
- Enumeration results vary by method (`basic|partial|full`) and step budget.
- MCMC quality is sensitive to runtime and proposal behavior.

### Known Limitations / Current Issues
- Large concurrent long-MCMC gallery runs can consume substantial resources.
- Grammar search remains hard for alternating motifs (for example staircase diagonals like repeated `down,right`).
- The trace option currently records inference samples in `infer` mode only.

### Minimum Handoff Checklist
- Build succeeds with `make`.
- `./main --mode enumerate ...` runs and prints ranked programs.
- `python3 make_gallery.py ...` generates `gallery/index.html`.
- `--trace-path` creates a TSV file for a short `infer` run.
